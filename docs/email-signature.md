# Email signature drafts

Three flavors below — pick whichever fits your tone. Paste into:

- **Gmail:** Settings (gear) → See all settings → General → Signature → Create new
- **Outlook:** File → Options → Mail → Signatures
- **Apple Mail:** Mail → Settings → Signatures
- **Mac/iPhone Mail app:** Settings → Mail → Signature

Most clients let you paste rich HTML; some only accept plain text. Both formats are below.

---

## Version A — Minimal (recommended for job applications)

Clean, no logo, fits everything from Gmail compose to mobile. Most professional for recruiters reading on a phone.

**Plain text:**

```
Nanda Kumar
Software Engineer · GenAI & Automation
nandakumaronline.com · +91 92062 57512
linkedin.com/in/nanda-kumar-profile · github.com/nandakumar1052
```

## Version C — One-liner (for replies within a thread)

Use a shorter sig for follow-up replies so you don't pile up signatures down the thread.

```
— Nanda · nandakumaronline.com
```

---

## What to leave OUT of your signature

- Email address — it's already in the From field; repeating it is noise
- "Sent from my iPhone" — manually remove this in mobile mail settings
- Quotes or aphorisms — recruiters skip past them; never adds value
- A literal image of your photo — most ATS/recruiter inboxes block embedded images, you end up looking like `[Image]`
- Long compliance footers ("This email may contain..." etc.) — fine for corporate accounts, distracting for personal job-search emails
